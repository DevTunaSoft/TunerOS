# Feature status — TunerOS

**Status snapshot: 2026-11-11 (merged early alpha; latest code CI PASS, device acceptance NOT RUN).** Source changes are not equivalent to a passing CI build or device acceptance.

| Capability | Status | Evidence / limitation |
|---|---|---|
| In-app autonomous self-tests | CODE IMPLEMENTED; CI/device UNVERIFIED | Unattended startup and import-triggered smoke suite, bounded private reports, real import/playback numeric observations, optional report sharing; hardware/long-run fault tests NOT RUN |
| Android TV + phone single app | Implemented, UNVERIFIED on devices | Launcher and Leanback entries, placeholder icon/banner |
| M3U import | Implemented, PASS (CI), device UNVERIFIED | Bounded lines and 25k-channel import; source-scoped IDs, capped accepted-ID set and pooled headers; regression tests for overflow and duplicates |
| XMLTV import | Android compatibility/security hardening pending CI; device UNVERIFIED | Streaming SAX XMLReader with mandatory lexical DTD rejection and external-entity denial; avoids unsupported Android JAXP flags. Bounded titles/names (256) and optional descriptions (2,048). New JVM security tests, real Android importer acceptance NOT RUN |
| XMLTV description retention | PASS (CI), device UNVERIFIED | Android import discards descriptions not displayed by the current alpha UI. Optional time-window retention remains disabled to preserve future-only schedules and the hide-no-EPG filter. No measured RAM improvement claimed. |
| EPG lookup/search responsiveness | Implemented, PASS (CI), device UNVERIFIED | Channel schedules sorted in place, binary-search indexed windows, no intermediate current-program pair lists; all imported channels accessible via virtualized ListView, filter results cached, 160ms search debounce |
| Hide channels without EPG | Implemented, PASS (CI), device UNVERIFIED | Checks for any schedule, including future programmes |
| Playlist/guide URL confidentiality | Implemented, device UNVERIFIED | Android Keystore AES-GCM; migrates legacy plaintext preferences |
| HTTP source downloader | Implemented, PASS (CI), device UNVERIFIED | HTTPS downgrade blocked, gzip sniffing, decompressed size limit; unit regressions |
| Media3 playback | Implemented, PASS (CI), device UNVERIFIED | Reuses player for same-header live-channel switches; releases for differing provider headers/onStop. HLS/DASH/native playback built but real-device streams untested |
| Stream Doctor | PASS (CI), device UNVERIFIED | Pure Kotlin Media3 code classifier; credential-free actionable messages for live and recording playback; unit tests, no network/logging/retry threads. Not a full player telemetry recorder |
| Guide Doctor | Planned | No mapping repair UI |
| DVR/PVR recording foundation | IN PROGRESS; PASS (CI), device UNVERIFIED | Raw/progressive capture and unencrypted MPEG-TS HLS capture are wired to the foreground recorder with bounded direct-to-disk I/O. HLS supports master-variant selection, live-edge start, media-sequence deduplication, gap detection, byte ranges with length and HTTP Content-Range offset validation (CI PASS), HTTPS downgrade protection, provider User-Agent/Referer headers, stalled-playlist detection, bounded manifests, zero-read busy-loop protection for raw streams, and one reusable 64 KiB segment buffer per active recorder. Encrypted HLS, fMP4 HLS/EXT-X-MAP, master variants requiring separate external audio/video rendition capture, and DASH recording fail closed and remain unsupported. SQLite catalog, recording library/playback, interruption recovery, exact-alarm future scheduling/re-arm in stable 200-item batches with one shared schedule database helper and per-job error isolation, overlap rejection, schedule cancellation, duplicate-ID overwrite protection, and secure encrypted scheduled-source/header storage are implemented. Manual protect/unprotect and path-validated deletion are implemented with a v3 catalog flag; the database migration is device UNVERIFIED. User-selected local SAF storage (shared/SD/USB) is now implemented in source with persisted read/write grants, no broad storage permission, provider-reported free-space enforcement, direct streaming output, content-URI playback/deletion validation, no silent fallback when selected media is unavailable, and metadata preservation when a drive is disconnected. CI PASS: run 42848491493. Physical USB/SD acceptance remains UNVERIFIED. Series rules, timeshift, and real-device acceptance remain pending. |
