# QA-50 — bounded EPG import admission host gate

Zero-dependency, offline host gate over the real compiled pure-Kotlin
`core/src/main/kotlin/com/devtunasoft/tuneros/core/GuideParser.kt`. No production file,
Gradle file, workflow, shared document or sibling QA path is edited. Base SHA:
`a523c2e43d198ee752f7c4f03f9f7853356ffb30`.

## Slice and non-duplication

One bounded seam: a future-only guide window is applied at **import time**, and only rows that
overlap the half-open window consume the `maxPrograms` admission cap. A row that ends exactly at
the window start or starts exactly at the window end is excluded; a row with zero or negative
duration, a blank channel, a blank title or an invalid timestamp is excluded; field truncation
and channel-name overflow are reported without aborting the parse. Every other input fails closed.

The audit scanned 99 local and origin QA worker refs and a 10,908,849-byte cross-branch gate
corpus. The symbols `GuideWindow`, `skippedPrograms`, `MAX_PROGRAMS`, `MAX_CHANNELS` and
`"programmes omitted"` had zero hits in QA gate scripts, fixtures and androidTest sources.
Prior work is adjacent but distinct: QA-02 covers future-only UI visibility; QA-05 covers
name search; QA-06 models a large paged guide with no parser or import window; QA-15 calls
`GuideParser.parse` with **no** window and checks retention, later `programsBetween` queries and
fail-closed variants; QA-27 covers theme tokens; CORE-52 covers HLS attribute shapes; CORE-44
covers `parseTime` proleptic-year handling. Core JVM tests assert two small window cases, but
there was no deterministic byte-exact host fixture gate with RED controls over this seam.

## Acceptance

1. Six scratch fixture files regenerate byte-identically with pinned SHA-256 digests.
2. Twelve scratch negative controls each exit nonzero with a distinct pinned FIRST code.
3. Mutation and GREEN leave every owned source, production input and committed fixture byte unchanged.
4. GREEN drives the real parser over 17 import rows for six cycles: eight admitted, two
   window-admitted overflow rows refused, six corrupt variants rejected, three field caps enforced.
5. Bounded heap and thread usage are asserted; diagnostics carry no derived marker and no
   address, credential, secret, PIN or recording-payload pattern.
6. Offline AGP androidTest compile/assembly is attempted and reported honestly. Device execution
   is BLOCKED / UNVERIFIED without an authorized adb target.
