## What is verified

The gate compiles the real production sources `TimelineFocusPolicy.kt`,
`TimelineLayout.kt` and `Models.kt` with the offline Kotlin 2.0.21 compiler and
calls `shiftedIndex` through the fixture-parsed rows. The committed fixture is
regenerated byte for byte and pinned by SHA-256. Nineteen checks cover header,
row bounds, manifest, byte identity, pinned mirror digest, cap binding, nine
fail-closed corrupt variants, six semantic families, direction guard, absence
of retained policy state, the full verdict matrix, privacy scan and stable heap
and thread counts. Twelve negative controls must all exit nonzero with their
pinned FIRST code; production and all owned files are hashed before and after
the mutation sweep. The green run uses `-Xmx96m`; a growing heap or any new
QA-named thread fails it. Diagnostics carry only check ids, counts, digests and
exception-free status text; the runtime-derived marker is never written to a
fixture, report or heartbeat.
