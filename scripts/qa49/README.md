# QA-49 — bounded SAF tree admission host gate

Deterministic, offline, zero-new-dependency host gate over the real production
`app/src/main/java/com/devtunasoft/tuneros/SafStorageInspector.kt`. No production file,
Gradle file, workflow, shared document or sibling QA path is edited. Base SHA:
`a523c2e43d198ee752f7c4f03f9f7853356ffb30`.

## Slice and non-duplication

The gate exercises one bounded seam: a SAF tree is admitted only when the scheme and
authority are exact, the tree document id is non-blank, the directory cursor is
create-capable, and the selected mounted volume reports non-negative usable space; every
other input fails closed and no URI reaches diagnostics.

Audit before authoring scanned 279 local and origin worker refs. Cross-branch corpora:
QA gate scripts 3,090,596 bytes, core tests 92,270,277 bytes, androidTest 1,131,886 bytes.
The symbols `SafStorageInspector`, `SafStorageInfo`, `EXTERNAL_STORAGE_AUTHORITY`,
`FLAG_DIR_SUPPORTS_CREATE` and `getTreeDocumentId` had zero hits across all three corpora.
Prior tasks cover adjacent but distinct behavior: QA-17 SAF destination selection,
QA-44 the timeshift ring filesystem seam, QA-43 committed-source hygiene,
QA-36 malformed address redaction and QA-46 HTTP identity-length completion.

## Acceptance (defined before implementation)

1. Committed fixture regenerates byte-identically from fixed constants and a pinned SHA-256 manifest.
2. Nine scratch negative controls each exit nonzero with a distinct pinned FIRST code.
3. Mutation leaves every owned source file and every committed fixture byte unchanged.
4. GREEN drives the real compiled production unit over all 72 rows for six bounded cycles,
   admits exactly 16 rows per cycle, refuses all other rows, and detects no leak.
5. Heap growth stays under 24 MiB against a 96 MiB cap and thread drift stays within 2.
6. Offline AGP androidTest assembly is attempted and reported honestly; device execution
   stays BLOCKED / UNVERIFIED without an authorized adb target.
