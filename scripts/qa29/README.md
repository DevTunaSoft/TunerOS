QA-12 owns crash recovery and QA-25 owns paging; neither decides the final
state of a capture. QA-29 owns that distinct, bounded slice: a COMPLETED

and never edits it.

The host gate compiles the real RecordingModels.kt together with Models.kt and
the shared Qa29Contract.kt using the offline Kotlin 2.0.21 compiler jars. The
JVM runs with -Xmx96m and checks heap use, thread drift and fixture identity.

Fixture contract
----------------
qa/fixtures/qa29 holds contract.txt, dimensions.tsv, cases.tsv (59 rows in six
families), corrupt.tsv (8 malformed rows), sha256.txt and .gitattributes.
Every id and token is symbolic. Regeneration is clock-free and network-free;
sha256.txt and Qa29Contract pin the generated bytes. No feed address,
credential, PIN, secret, DRM key or recording payload is stored in any file.

Device execution
----------------
Instrumentation sources and the manifest entry compile/package with AGP when a
local SDK is available. Running them needs an attached authorized device or
emulator. Without one the device verdict is BLOCKED / UNVERIFIED and is never
reported as a PASS.
