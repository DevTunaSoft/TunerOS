# QA-55 scratch fixture

Generated by `scripts/qa55/run.sh generate`. Do not hand-edit.

`dimensions.tsv` pins the registry, case, channel, programme, corrupt and token
counts plus the guide and mirror digests. `cases.tsv` is the bounded token
admission table (raw token, canonical form, decision, fail-closed code).
`corrupt.txt` stores hex-encoded malformed XMLTV documents by name.
`guide.xmltv` is a bounded synthetic guide with 48 channels and 120 programmes,
including a blank title, an over-long title and injected category/genre tokens.
`report-copy.txt` is a sample diagnostics file for the privacy-scan control.
`sha256.txt` pins the digest of each data file.

Every name is invented scratch data. No URL, credential, PIN or media payload
is present. Byte identity is enforced with `* -text` in this directory.
