QA-64 bounded width-unit fixture
=================================

All values are invented scratch data. The four data files are regenerated byte for byte from
constants in Qa64Assertions.kt. sha256.txt pins the data-file digests; it is not itself pinned
inside dimensions.tsv. Line endings are LF and are fixed by .gitattributes.

Files
  dimensions.tsv  pinned shape and golden journal digest
  cases.tsv       timeline duration and scale rows with reference widths
  corrupt.tsv     rejected variants
  sha256.txt      data-file digests

Regenerate with: bash scripts/qa64/run.sh generate
